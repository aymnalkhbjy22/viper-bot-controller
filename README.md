An asynchronous Terminal Control Center (CLI) for administering and monitoring Telegram bots, broadcasting messages, and updating bot profiles on the fly.

---

## 👨‍💻 Developer
* **Main Developer:** Ayman Al-Khubji

---

## ⚡ Features
* **Profile Management:** Modify bot name, description, about section, and avatar photo directly from the terminal.
* **Mass Broadcast:** Broadcast messages to stored users with rate-limiting protection.
* **Live Message Monitor:** Real-time incoming traffic terminal logger.
* **User Persistence:** Automatically saves user interactions in JSON storage.
* **Async Engine:** Powered by `asyncio` and `python-telegram-bot` v20+.
